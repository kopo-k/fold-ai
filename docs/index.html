fold

Features

邪魔をせず、必要な操作だけ足す

ホストページのDOMは壊さず、追加とスタイル付与だけで動きます。フレームワーク非依存。

01

回答ごとのトグル

各回答の先頭にワンクリックの開閉。▾ 展開中／▸ 折りたたみ中で状態がひと目で分かる。
02

自動折りたたみ

長い回答（既定 8行 超）は自動でたたむ。しきい値は設定で変更できる。
03

右端ミニマップ

1回答＝1セグメント。スクロールせずどの回答もその場で開閉でき、今見ている位置もハイライトされる。
04

一括ショートカット

Alt+Shift+F で全回答を一括開閉。画面のどこにいてもキー一発。
05

サイトごと設定

ChatGPT / Claude / Gemini を個別に ON / OFF。使いたいサイトだけで動かせる。
06

検索・コピー維持

display:none ではなく max-height で折りたたむため、たたんだ回答でも ページ内検索とコピーが効く。
fold

Privacy

会話は、どこにも送らない

ネットワークリクエストを一切発行しません。解析・テレメトリ・リモート設定なし。保存するのは拡張の設定だけです。

  • 外部サーバーへの通信は一切なし（会話も設定も送信しない）
  • 会話内容・Cookie・ログイン情報には触れない
  • <all_urls> も tabs 権限も要求しない
  • ソースは全公開（MIT）。ビルドは pnpm install && pnpm build だけ
要求する権限 用途
storage 拡張の設定を保存（しきい値・ショートカット・サイト別ON/OFF）
chatgpt.com 回答を検出しUIを挿入
claude.ai 同上
gemini.google.com 同上（必要最小限のホストのみ）
